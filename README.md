# PrismBeacon

PrismBeacon enables real-time data ingestion and processing across distributed systems, optimizing infrastructure scalability and load balancing architecture.

With PrismBeacon, you get a lightweight tool that stays out of your way.

**What you get**

- PrismBeacon enables real-time data ingestion
- and processing across distributed systems,
- optimizing infrastructure scalability and load

## Technology Stack

- rust
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/PrismBeacon.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
